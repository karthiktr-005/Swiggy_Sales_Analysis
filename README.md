# Swiggy_Sales_Analysis
Performed end-to-end data cleaning on raw transactional data from Swiggy, handling nulls, blanks, and duplicate records using SQL window functions.Segmented customer spending into price buckets to understand purchasing behavior.

# Overview
This project analyzes food delivery transactions to uncover revenue trends, customer behavior, and cuisine performance. The workflow includes data cleaning, dimensional modeling, KPI development, and analytical reporting using SQL.

# Objectives 
Clean raw transactional data
Remove duplicates using ROW_NUMBER()
Design Star Schema for analytics
Build KPIs
Perform time, location, food, and rating analysis

# Tools
SQL Server
Window Functions
Star Schema Modeling

# Key Outcome
Built a production-style analytical database enabling fast reporting and actionable insights on food delivery performance.
